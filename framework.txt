1. REQUEST LIFECYCLE
================================================================================

HTTP Request
  -> public/index.php
    -> require ../autoload.php (custom PSR-4 spl_autoload_register)
    -> new \App\App()
    -> $app->_run()
      -> App::_run() calls parent::_run() (Aether::_run())
        -> Aether::__init()
          1. Error reporting (DEV mode = E_ALL + display_errors)
          2. include_once CoreHelperFunctions.php (Aether(), _debug(), _root())
          3. ProjectConfig::_load() — merges .env into $_ENV (APCu-cached 10min)
          4. SessionHandler::_load() — starts session with secure cookies
        -> Pipeline::_run(self::$_middlewares, fn() => ControllerGateway::_link())
      -> App sets self::$_middlewares (middleware class list)
      -> App calls ModuleFactory::_load([])

      Pipeline final handler: ControllerGateway::_link()
        -> Checks ENABLE_ROUTE_CACHING config flag
        -> If enabled + APCu hit: loads cached route table
        -> If miss: scans controllers via ReflectionClass, extracts PHPDoc annotations
        -> Builds Route objects, optionally caches compiled table in APCu (TTL 3600s)
        -> Router::_run() matches REQUEST_URI against routes
        -> Executes matched controller method with sanitized params

9. ROUTER SYSTEM
================================================================================

--- 9.1 ControllerGateway (src/Aether/Http/Router/Controller/ControllerGateway.php) ---

Namespace: Aether\Http\Router\Controller
Class: ControllerGateway (final)

Constants:
  CACHE_KEY = "aether::routes::compiled//"
  CACHE_TTL = 3600

Flow:
  1. Check ENABLE_ROUTE_CACHING env flag
  2. If enabled + APCu hit: load cached routes JSON
  3. On miss: scan controllers:
     - glob("app/App/Controller/*.php") with namespace "App\Controller\"
     - glob("app/App/Controller/Api/*.php") with namespace "App\Controller\Api\"
  4. For each file: ReflectionClass -> get @base from class doc
  5. For each public method: extract @method, @route, @middlewares
  6. Register route: router->_addRoute(METHOD, base + route, "Class@method", middlewares)
  7. If caching enabled: serialize route table as JSON in APCu
  8. Call router->_run()

Annotation format (in PHPDoc):
  [@base] => /api/v1                     (optional, on class)
  [@method] => GET                       (required, on method)
  [@route] => /users/{id}                (required, on method)
  [@middlewares] => AuthMiddleware        (optional, comma-separated)

Regex for extraction: /\[@{annotation}\]\s*=>?\s*(\S+)/


--- 9.2 Router (src/Aether/Http/Router/Router.php) ---

Namespace: Aether\Http\Router
Class: Router (final)
Traits: UserInputValidatorTrait

Properties:
  - $_routes = ["GET" => [], "POST" => [], "DELETE" => [], "PUT" => [], "QUERY" => []]

Methods:
  - _addRoute(string $method, string $route, $callable, $middlewares) : Router
  - _run() : bool
    1. Parse REQUEST_URI (path only via parse_url)
    2. Check exact match (trimmed slashes)
    3. Check regex match: {param} -> ([^/]+)
    4. If matched -> _execute(route, params)
    5. No match -> 404
  - private _execute(Route $route, ?array $params) : mixed
    1. Run per-route middlewares via Pipeline::_runForRoute()
    2. Sanitize params via _sanitizeInput()
    3. Resolve callable: string "Class@method" -> instantiate + call

--- 10.2 Pipeline (src/Aether/Middleware/Pipeline.php) ---

Namespace: Aether\Middleware
Class: Pipeline (final)

Methods:

--- 10.3 Built-in Middleware (src/Aether/Middleware/Stack/) ---

MaintenanceMiddleware:
  - If $_ENV["MAINTENANCE"] === "true" -> 503 response (JSON or HTML) + exit

RatelimitMiddleware:
  - Uses APCu cache (Aether()->_cache()->_apcu())
  - Key: "ratelimit://{IP}"
  - Configurable: RATELIMIT_MAX_LIMIT (default 100), RATELIMIT_SECOND_INTERVAL (default 60)
  - On exceed: 403 response (JSON or HTML based on Accept header)
  - TTL: 1 hour per entry

HttpFilteringMiddleware:
  - Anti-replay protection for non-GET requests
  - Skips GET requests (EXCLUDE_GET = true)
  - Key: "filtering://{METHOD}:{IP}:{ROUTE}" in APCu (TTL: 1 second)
  - Blocks duplicate identical requests within 1 second window
  - On block: 403 response (JSON or HTML)

CsrfMiddleware (final):
  - On GET/HEAD/OPTIONS: exposes token via X-CSRF-Token header
  - On POST/PUT/DELETE/PATCH: validates csrf_token from body (php://input) or X-CSRF-TOKEN header
  - Uses CsrfToken::_verify() (timing-safe, anti-replay: regenerates after use)
  - On failure: 403 response (JSON or HTML)

SecurityHeadersMiddleware:
  - X-Content-Type-Options: nosniff
  - X-Frame-Options: DENY
  - Referrer-Policy: strict-origin-when-cross-origin
  - Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()
  - Cross-Origin-Opener-Policy: same-origin
  - Cross-Origin-Resource-Policy: same-origin
  - Strict-Transport-Security: max-age=31536000; preload (HTTPS only)

CspMiddleware:
  - Content-Security-Policy header:
    default-src 'self'; script-src 'self'; style-src 'self'; img-src 'self';
    font-src 'self'; connect-src 'self'; frame-src 'none'; object-src 'none';
    base-uri 'self'; form-action 'self'; frame-ancestors 'none';

JwtMiddleware (final):
  - Extracts Bearer token from Authorization header or ?token query param
  - Verifies via JWToken::_verify()
  - On failure: 401 response (JSON or HTML)
  - On success: injects decoded payload into $_REQUEST['__jwt_payload']

AuthMiddleware:
  - Checks Aether()->_session()->_auth()->_isLoggedIn()
  - On failure: 403 response (JSON or HTML)

--- 13.3 SessionSecurityLayer (src/Aether/Http/Session/Security/SessionSecurityLayer.php) ---

Namespace: Aether\Http\Session\Security
Class: SessionSecurityLayer (abstract)

All session values are stored encoded.

Encoding: base64( json_data + ":::" + HMAC-SHA256(json_data, SESSION_HMAC) )

_encodeNode($key, $data) : string
  1. If array -> json_encode
  2. Concatenate: data + ":::" + hash_hmac('sha256', data, SESSION_HMAC)
  3. base64_encode result

_decodeNode($key) : mixed
  1. base64_decode $_SESSION[$key]
  2. Split on ":::" -> rawData + hmacSignStr
  3. Verify HMAC with HmacSignature::_hmacEquals()
  4. json_decode rawData (returns raw string if not valid JSON)
  5. Return decoded data (or null on tamper)

    -> Creates JWT with header (alg: HS256, typ: JWT)
    -> Injects registered claims: iat, exp, nbf
    -> Signs with JWT_SECRET env var
    -> Returns header.payload.signature

  static _decode(string $token) : array|false
    -> Validates 3 segments
    -> Algorithm pinning: rejects non-HS256 headers
    -> Timing-safe signature verification
    -> Temporal claims validation (exp, nbf)
    -> Returns payload array or false

  static _verify(string $token) : bool
    -> _decode() !== false

  static _refresh(string $token, ?int $ttl = null) : string|false
    -> Decodes, strips registered claims, re-encodes with new TTL

  static _getPayload(string $token) : array|false
    -> Decodes payload WITHOUT signature verification (for inspection)

  static _expiresIn(string $token) : int|false
    -> Returns seconds remaining before expiration

  Private helpers: _sign(), _base64UrlEncode(), _base64UrlDecode()

ViewInstance (src/Aether/View/ViewInstance.php)

Namespace: Aether\View
Class: ViewInstance (final, implements ViewInterface)

PHP template renderer with security hardening.

Properties: $_path, $_vars, static $_ext = "php"

_render():
  1. Resolve views root: realpath("views") (relative to public/)
  2. Validate path: no "..", no absolute, regex /^[a-zA-Z0-9_.\-\/]+$/
  3. Build full path: viewsRoot/path.{ext}
  4. realpath() check: must stay within viewsRoot (no traversal)
  5. If extension != "php" -> file_get_contents (no execution)
  6. If extension == "php":
     - extract($vars, EXTR_SKIP) -> make vars available
     - ob_start() + require_once + ob_get_clean() + echo

Static:
  _make(string $path, array $vars) -> shortcut constructor + render
  _getExtension() / _setExtension() -> default "php", configurable

ViewInterface:
  _render(), static _make(string $path, array $vars)
